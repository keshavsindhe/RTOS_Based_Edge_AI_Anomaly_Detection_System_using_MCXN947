## Build Steps

### 1. Add TensorFlow Lite Micro Library
Download TFLite Micro for Cortex-M33:
- Source: https://github.com/tensorflow/tflite-micro
- Add to project: third_party/tflite-micro/

### 2. Update CMakeLists.txt
Add these lines:

```cmake
# TensorFlow Lite Micro
set(TFLITE_MICRO_DIR ${CMAKE_SOURCE_DIR}/third_party/tflite-micro)
include_directories(${TFLITE_MICRO_DIR})

# ML Source Files
file(GLOB ML_SOURCES "ml/*.c" "ml/*.cc")
target_sources(${MCUX_SDK_PROJECT_NAME} PRIVATE ${ML_SOURCES})

# C++ Support (for TFLite)
set_source_files_properties(
    ml/tinyml_engine.c
    PROPERTIES LANGUAGE CXX
)

# Link Math Library
target_link_libraries(${MCUX_SDK_PROJECT_NAME} m)
```

### 3. Build Test Program
```powershell
# Clean build
cmake --build debug --clean-first

# Or rebuild
cmake --build debug
```

### 4. Flash to FRDM-MCXN947
Use MCUXpresso IDE or J-Link:
```
JLinkExe -device MCXN947 -if SWD -speed 4000
> loadfile debug/edge_ai_vibration.elf
> r
> g
```

## Troubleshooting

### Build Errors
- Missing TFLite headers: Add tflite-micro to include path
- Linker errors: Enable C++ compilation for .c files using TFLite
- Math library: Add -lm to linker flags

### Runtime Errors
- Model version mismatch: Regenerate model_data.cc with correct TFLite version
- Tensor allocation failed: Increase TINYML_TENSOR_ARENA_SIZE
- Wrong predictions: Check feature scaling and model input order

### UART Issues
- No output: Check UART baud rate (115200)
- Garbled text: Check clock configuration
- Incomplete output: Increase UART buffer size
